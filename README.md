# q3atwork

Improve Team cohesion by hosting a quake server in your own network!

## Prereqs:

- [Ioquake3](https://files.ioquake3.org/Linux.zip)
- Quake 3 Game files
    - you'll want the final release 1.32c
    - if you're super cool, find a physical copy, or you can buy a digital copy from [multiple places](https://ioquake3.org/buy/)
- [ko](https://ko.build/) - used to build an image for the q3http (for the healthcheck endpoint)
